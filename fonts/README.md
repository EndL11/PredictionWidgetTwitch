# Шрифт у стилі GTA

Теми `vice`, `slant`, `hud` у віджеті прогнозів і всі стилі таймера шукають шрифт **Pricedown**, встановлений у Windows (`Pricedown`, `Pricedown Bl` або `Pricedown Black`). Якщо його нема, підставляється Impact або Arial Black.

## Встановлення на ПК зі стрімом

1. Скачайте безкоштовний набір шрифтів з офіційного сайту автора: <https://typodermicfonts.com/downloads/> (архів `typodermic-free-fonts-*.zip`).
2. Знайдіть в архіві `Pricedown Bl.otf`, клацніть правою кнопкою → **Встановити**.
3. Перезапустіть OBS, щоб він побачив новий шрифт.

Шрифт має кирилицю, тож «МАРАФОН» і українські назви відображаються ним.

## Чому файлу шрифту нема в репозиторії і на сайті

Безкоштовна ліцензія Typodermic Desktop EULA дозволяє використовувати шрифт на своєму комп'ютері, але **не дозволяє** викладати його на сайт як webfont: для цього потрібна платна ліцензія. Тому віджети беруть шрифт лише з системи (`local()`), а цю папку не використовують для файлів шрифтів.
